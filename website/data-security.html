Data Security & Deletion Policy

Effective Date: January 31, 2025

Last Updated: January 31, 2025

1. Data Security Overview

Restohand is committed to protecting your personal information and maintaining the highest standards of data security. This policy outlines our security measures and your rights regarding data deletion.

2. Security Measures

2.1 Technical Safeguards

  • Encryption: All data is encrypted both in transit (TLS 1.3) and at rest (AES-256)
  • Secure Infrastructure: Hosted on Google Cloud Platform with enterprise-grade security
  • Authentication: Multi-factor authentication and JWT-based secure access controls
  • Database Security: MongoDB with role-based access controls and connection encryption
  • API Security: Rate limiting, input validation, and secure API endpoints
  • File Storage: Secure Firebase Storage with controlled access permissions

2.2 Administrative Safeguards

  • Access Controls: Strict role-based permissions (Manager, Waiter, Customer)
  • Staff Training: Regular security awareness training for all personnel
  • Security Audits: Regular third-party security assessments and penetration testing
  • Incident Response: 24/7 monitoring and rapid incident response procedures
  • Data Minimization: We collect only the data necessary for service operation

2.3 Physical Safeguards

  • Secure Data Centers: Google Cloud Platform's SOC 2 compliant data centers
  • Environmental Controls: Climate-controlled, monitored environments
  • Access Restrictions: Biometric access controls and 24/7 security surveillance

3. Data Categories We Collect

Staff Data:

  • Account information (name, email, phone, role)
  • Work performance metrics and order handling records
  • Shift schedules and attendance data
  • Location data (when on duty)
  • App usage analytics

Restaurant Data:

  • Menu items, categories, and pricing information
  • Order processing and transaction records
  • Inventory and stock management data
  • Customer interaction logs

Technical Data:

  • Device information and app diagnostics
  • Usage patterns and performance analytics
  • Security logs and access records
  • Error reports and crash analytics

4. Data Retention Periods

Data Type Retention Period Purpose
Account Information 3 years after termination Legal compliance, payroll records
Performance Data 2 years Management, improvement
Transaction Records 7 years Tax, accounting compliance
Technical Logs 90 days Security, troubleshooting
Analytics Data 2 years Service improvement

5. Your Data Deletion Rights

5.1 Right to Deletion

You have the right to request deletion of your personal data under the following circumstances:

  • The data is no longer necessary for the original purpose
  • You withdraw consent (where consent was the legal basis)
  • The data has been unlawfully processed
  • Deletion is required for legal compliance
  • You object to processing and there are no overriding legitimate grounds

5.2 Data Deletion Process

How to Request Data Deletion:

  1. Submit Request: Email us at privacy@restohand.com with "Data Deletion Request" in the subject line
  2. Identity Verification: We will verify your identity using secure authentication methods
  3. Review Process: We review your request within 5 business days
  4. Deletion Timeline: Data deletion completed within 30 days of verified request
  5. Confirmation: You receive confirmation once deletion is complete

5.3 Limitations to Deletion

We may retain certain data when deletion would:

  • Violate legal or regulatory requirements (tax records, employment law)
  • Be necessary for legitimate business interests (fraud prevention, security)
  • Be required for legal claims or litigation
  • Impact the rights and freedoms of others

6. Automated Data Deletion

RestoHand implements automated data deletion processes:

  • Session Data: Automatically deleted after 24 hours of inactivity
  • Temporary Files: Purged every 7 days
  • Log Files: Automatically archived and deleted per retention schedule
  • Inactive Accounts: Dormant accounts archived after 2 years of inactivity

7. Data Portability

Before deletion, you can request a copy of your personal data in a structured, machine-readable format. This includes:

  • Account information and profile data
  • Work history and performance records
  • Personal preferences and settings
  • Communication history (where legally permissible)

8. Third-Party Data Deletion

When you request data deletion, we also coordinate with our trusted service providers:

  • Google Cloud Platform: Secure deletion from all storage systems
  • Firebase: Removal from authentication and analytics systems
  • Razorpay: Transaction data handled per their deletion policies
  • Analytics Providers: Anonymization or deletion of tracking data

9. Data Breach Response

In Case of a Data Breach:

  • Immediate Response: Breach contained within 24 hours
  • Investigation: Full forensic analysis conducted
  • Notification: Affected users notified within 72 hours
  • Regulatory Reporting: Authorities notified as required by law
  • Remediation: Additional security measures implemented
