Marketplace aggregators
Online businesses that sell multiple products through different vendors can now use Easy Split to manage the splitting of incoming customer payments with ease. Also, easily manage schedule options, deduct commission, and view real-time reports for these vendor payments using our Easy Split product dashboard.

Standard Marketplace Setup
Add and update vendor details: Add and update vendor details via product dashboard or API.
Prepaid charge configuration: Reduces effort from the merchant finance team in reconciling the service charges to settle fee invoices.
Split after payment: Allows order split default delay 2 days (can be extended further if required).
Manage refunds: Allows refund both before and after the split.
Transfer balances: Allows credit/debit vendor account.
Deferred settlement: Allows deferred settlement time configuration basis service time for each vendor. It should be used only when there is a different settlement time for the same order.
